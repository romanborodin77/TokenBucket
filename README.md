# TokenBucket

Локальное хранилище для Windows: API-токены, учётные данные, SSH-ключи, простые значения и текстовые документы.
Шифрование выполняется на компьютере пользователя. Хранилище не обращается к сети; HTTP(S)-адрес можно отдельно открыть в браузере.

Автор: **Роман Бородин** <workplace-it@rambler.ru> · версия 1.0 · лицензии компонентов — `docs/licenses/`

## Возможности

- **Хранилище одного файла** (`vault.tb` в каталоге данных пользователя): проекты и группы до 8 уровней вложенности, до 10 000 записей, секрет до 1 МиБ.
- **Криптография**: XChaCha20-Poly1305 со случайным nonce на операцию; ключ данных заворачивается ключом из мастер-пароля (Argon2id, 64 МиБ, opslimit 3) или DPAPI учётной записи (Windows Hello). Параметры KDF проверяются при чтении — понижение невозможно.
- **Разблокировка**: мастер-пароль или Windows Hello; сменяемая в обе стороны; экспорт/импорт защищённого контейнера для переноса.
- **Записи**: API-токен, логин/пароль, SSH-ключ, простое значение (текст/IP/URL), текстовый файл со строками. Все типы зашифрованы. Теги, избранное, повторная проверка и сроки действия сохраняются.
- **Реестр и TXT**: вкладка «Реестр» использует общие группы, поиск и фильтры. TXT импортируется через предпросмотр типов, групп и конфликтов; повторные ключи сохраняются отдельно, снимок исходника — точными байтами. Старые записи преобразуются только отдельным подтверждённым действием для выбранного ресурса.
- **Выдача секретов**: копирование с настраиваемой автоочисткой буфера через 10/20/30/60 с (20 с по умолчанию) (исключение из истории и облачной синхронизации), быстрая вставка по Ctrl+Alt+Space (сохранённое сочетание сохраняется), выдача в переменные окружения (временно — в запущенный процесс, постоянно — в HKCU\Environment с предупреждением), сохранение SSH-ключа во временный файл с правами только владельцу.
- **Защита сеанса**: автоблокировка по таймеру (1–60 мин), блокировка при уходе из сеанса Windows и переходе в сон; единственный экземпляр через lock-файл.
- **Память**: ключи и сериализуемые секреты — в защищённых буферах libsodium (`sodium_malloc`, guard-страницы); при сохранении открытый текст не проходит через обычную кучу (собственный CBOR-писатель); аварийные дампы процесса запрещены.
- **Интерфейс**: тёмная/светлая тема, трей с состояниями и уведомлениями, сворачивание в трей, автозапуск с Windows, поиск с фильтрами и сортировкой, импорт из CSV и KeePass XML.

## Быстрая вставка (Windows)

Активируйте нужное поле другого приложения и нажмите Ctrl+Alt+Space (либо сохранённое сочетание). Найдите запись, выберите пароль, логин или токен и нажмите Enter либо «Вставить». Enter получателю не отправляется. В списке показаны тип и путь группы; SSH-ключи не выдаются этим способом. Для многострочного значения доступна только отдельная кнопка «Скопировать».

Панель показывает зафиксированного получателя. Без подтверждённого внешнего окна доступен ручной режим. При смене окна, блокировке, изменении записи или удержании модификаторов более 1,5 с операция отменяется до публикации. Повышенные/неизвестные процессы запрещены; автоматического копирования при отказе нет. Esc, повторный вызов и крестик отменяют операцию. В настройках допустимо одно сочетание Ctrl/Alt/Win с буквой, цифрой, Space или F1–F11; неудачная смена сохраняет прежнее сочетание.

Windows SendInput не гарантирует атомарное назначение ввода: смена фокуса сразу после последней проверки остаётся системным ограничением. Всегда сверяйте получателя перед выдачей.
## Настройки и восстановление

Ctrl+, открывает единое окно: общие настройки, безопасность, быстрая вставка, выдача секретов и резервные копии. Изменения применяются кнопкой «Сохранить»; при ошибке показано, что уже применено и что осталось в черновике. Отмена не применяет черновик. Срок показа секрета — 5/10/15/30 с; при закрытии можно свернуть в трей, заблокировать и свернуть либо выйти. Если трей недоступен, закрытие завершает приложение с блокировкой.

На странице копий доступны сведения о собственной `.bak` и «Восстановить…». Сначала проверяется пароль или Hello именно копии, затем запрашивается подтверждение с её датой. Перед заменой сохраняется уникальная зашифрованная страховочная копия текущего файла; после восстановления нужна обычная разблокировка. Несохранённый черновик настроек блокирует отдельные действия. Простое наличие `.bak` ещё не означает, что её содержимое проверено.

## Формат данных

Контейнер `TBVK` v1 и криптография сохранены; внутренняя модель — CBOR v4 с чтением v1–v4. Перед первой записью старого файла требуется согласие и проверенная зашифрованная копия. Прежний EXE не читает v4; для отката нужен старый файл и его прежний способ разблокировки. Защищённый экспорт тоже имеет формат v4, сохраняя локальный старый файл без изменения. [Описание новых полей и ограничений](docs/structured-storage-format.md).

## Сборка (Windows)

Инструменты: Visual Studio 2022+ (MSVC), CMake ≥ 3.30, vcpkg с манифестом `vcpkg.json` (Qt6 Widgets/Test/Concurrent/Network, libsodium). Версии зафиксированы в `docs/build/windows-toolchain.md`.

```cmd
tools\build.cmd            # конфигурация + сборка (Release)
tools\test.cmd             # полный CTest
tools\package-windows.cmd  # dist\TokenBucket + zip с зависимостями
```

## Структура

```
src/
  vault/     криптография, контейнер TBVK, CBOR-писатель, атомарное хранение
  model/     дерево узлов и записи, поиск, теги, CBOR v1–v3
  app/       Application (состояния/generation/busy), IdleTimer
  platform/  Windows: DACL-файлы, Hello/DPAPI, сессия, буфер, env, быстрая вставка,
             политика дампов; Linux-ветки (отложено до отдельной задачи)
  ui/        окна, редактор, карточка, трей, тема, брендинг
  io/        импорт CSV / KeePass XML
tests/       20 целей CTest: от крипто-юнитов до e2e через реальные диалоги
docs/        спека, планы, аудит и оценка защиты, приёмка, инструментарий сборки
```

## Безопасность

Обещания и границы защиты — в спеке (§4): файл защищён от чтения без ключа и от изменения; защита от вредоносного ПО в разблокированной сессии, администратора и снимков памяти **не входит** в объём. Аудит криптографии и сводная оценка с остаточными рисками — `docs/security/`.
