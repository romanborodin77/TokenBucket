# Локальная сборка Windows

- Для TokenBucket сборку, упаковку и все тесты, включая полный предрелизный прогон, выполнять только на этой рабочей станции. На COREI5 ничего не передавать.

- В этой рабочей среде готовую сборку всегда размещать в `D:/Sources/gitverse/TokenBucket/dist/TokenBucket/`.
- Основной ZIP: `D:/Sources/gitverse/TokenBucket/dist/TokenBucket-windows-x64.zip`.
- При сборке из worktree проверенный пакет также переносить в указанный основной каталог.
