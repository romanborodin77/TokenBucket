# Доступ локального агента к TokenBucket

Завершите уже запущенный TokenBucket, затем из каталога Windows-сборки запустите `TokenBucket.exe --agent-access` и разблокируйте хранилище. Флаг действует до выхода из приложения. `TokenBucket-agent.exe` из того же каталога читает один JSON-запрос из stdin и возвращает один JSON-ответ в stdout. Используйте абсолютный путь к помощнику в настройке инструмента агента. Передавайте запрос через stdin и дождитесь ответа, пока владелец подтверждает его в TokenBucket.

## Поиск и чтение

Пример для PowerShell 7. Сначала передайте точное название записи. Владелец разрешает передачу её названия, типа и ID. При нескольких совпадениях назначьте записям различные названия.

```powershell
$helper = Join-Path $PWD 'TokenBucket-agent.exe'
$find = @{ v = 1; op = 'find'; title = 'Deploy SSH' } | ConvertTo-Json -Compress
$match = $find | & $helper | ConvertFrom-Json
```

Затем используйте возвращённый UUID и имя одного поля. Нажатие «Да» открывает проверку мастер-паролем или Windows Hello даже для записи без настроенной повторной проверки. Каждый ключ и парольная фраза запрашиваются отдельно.

```powershell
if ($match.ok) {
    $read = @{ v = 1; op = 'read'; id = $match.entry.id; field = 'sshPrivate' } | ConvertTo-Json -Compress
    $result = $read | & $helper | ConvertFrom-Json
    if ($result.ok) { $keyBytes = [Convert]::FromBase64String($result.value) }
}
```

Чтобы получить открытый ключ, передайте `field = 'sshPublic'`. Для парольной фразы используйте `field = 'sshPassphrase'`.

| Тип в ответе поиска | Поля для чтения |
| --- | --- |
| `apiToken` | `token` |
| `credentials` | `login`, `password` |
| `sshKey` | `sshPrivate`, `sshPublic`, `sshPassphrase` |
| `plainValue` | `plainValue` |
| `textFile` | `textLine` и обязательный номер видимой строки `line`, начиная с `1` |

Для `textLine` используйте номер из редактора текстового файла. Строка должна быть отмечена как видимая. Например, `{"v":1,"op":"read","id":"01234567-89ab-4def-8123-456789abcdef","field":"textLine","line":2}` возвращает сохранённые UTF-8 байты строки без BOM файла и без перевода строки. Для SSH-ключей ответ сохраняет исходные байты, включая окончания строк. Другие поля возвращаются в UTF-8. Пустое поле может вернуть пустую строку base64.

## Формат и ошибки

В stdin передаётся одна строка UTF-8 без BOM, максимум 4096 байт до перевода строки. Поддерживается версия `v:1`, дополнительные или повторяющиеся параметры отклоняются. Поиск учитывает регистр. Ответ поиска содержит `{"ok":true,"entry":{"id":"…","title":"…","type":"…"}}`. Чтение возвращает `{"ok":true,"encoding":"base64","value":"…"}`. Максимальный размер исходного поля — 1 МиБ. Код выхода `0` означает успех. При ошибке код выхода `1`, ответ имеет вид `{"ok":false,"error":"…"}`.

| Код | Действие |
| --- | --- |
| `unavailable` | Проверьте флаг запуска, локальный сеанс и завершение предыдущего запроса. Такой ответ также возможен после отмены соединения или тайм-аута. |
| `locked`, `busy` | Разблокируйте приложение или дождитесь завершения открытого диалога либо операции. |
| `denied` | Владелец отклонил подтверждение или повторная проверка не прошла. |
| `stale` | Состояние записи изменилось во время подтверждения. Снова запросите запись. |
| `not_found`, `ambiguous` | Проверьте ID или точное название. |
| `unavailable_field` | Проверьте тип записи, имя поля и видимость строки. |
| `invalid_request`, `too_large` | Исправьте формат или размер данных. |

## Границы доступа

Интерфейс использует локальный именованный канал Windows с доступом для текущей учётной записи и проверкой сеанса. Windows отклоняет удалённые подключения. Запросы обрабатываются по одному, подтверждение одного поля ожидается до 60 секунд. По умолчанию выбран отказ. Проверяйте название, поле и номер строки в диалоге. PID относится к процессу, подключившемуся к каналу. Личность программы или агента, запустившего помощника, по этому PID не подтверждается. Механизм предполагает доверие к Windows и к процессам владельца, у которых уже есть доступ к его сеансу. [Права доступа к именованным каналам](https://learn.microsoft.com/en-us/windows/win32/ipc/named-pipe-security-and-access-rights), [режим локальных подключений](https://learn.microsoft.com/en-us/windows/win32/api/namedpipeapi/nf-namedpipeapi-createnamedpipew).

Успешный `read` передаёт значение вызывающему процессу. Блокировка отменяет ещё не отправленную выдачу. Полученные агентом данные отозвать невозможно. Base64 сохраняет байты и не шифрует их. История агента, инструмента или модели может сохранить ответ. Если агенту нужно выполнить команду с токеном, используйте временную выдачу переменной окружения прямо в доверенный процесс через приложение. Если SSH-ключ нужен только для команды, используйте штатную выдачу SSH-ключа из TokenBucket и передавайте инструменту путь к ключу. Так содержимое секрета не попадает в запрос модели. Мастер-пароль и подтверждение Hello вводятся только в диалоге приложения.

После обрыва соединения или истечения срока ответ агенту не отправляется. Системный диалог Windows Hello при этом может оставаться открытым. Следующий запрос доступен после завершения системной проверки.
