# Проверки SSH-команд через TokenBucket

Владелец включает исполнение отдельно от общего доступа MCP, выбирает сохранённую привязку и подтверждает команду. MCP получает вывод и статус, а OpenSSH использует ключ внутри локального контура TokenBucket.

## RED и GREEN

- Коммит `1448e86` добавил проверки выключенного режима и каталогов MCP. Локальная команда `ctest --test-dir build -C Release -R '^test_agent_win$' --output-on-failure` показала 11 пройденных тестов и 3 ожидаемых отказа. Брокер возвращал `invalid_request`, а оба каталога содержали три инструмента.
- После реализации в коммите `7c56fe4` та же команда прошла. Каталоги MCP содержали четыре инструмента, вызов при выключенном исполнении вернул `ssh_disabled` без окна согласия.
- Расширенный локальный прогон той же команды с изолированным SSH-сервером прошёл за 24,75 секунды. QtTest сообщил `19 passed, 0 failed, 0 skipped`. Синтетический зашифрованный ключ и записи о доверии хосту предоставил локальный тестовый сервер на `127.0.0.1`. Использовался установленный Windows OpenSSH 9.5p2.

## Что проверяет `test_agent_win`

| Проверка | Гарантия |
| --- | --- |
| `sshExecIsDisabledByDefault` | Вызовы CLI и MCP отклоняются до согласия, пока исполнение выключено. |
| `sshExecUsesExactBindingAndKeepsSecretsLocal` | Для исполнения нужны точный ID и однозначная привязка. Команда появляется в диалоге и поступает в SSH одним аргументом. Каждая команда требует повторной проверки. Парольная фраза, приватный ключ и временный путь отсутствуют в ответе MCP. |
| `sshExecNativeBoundaries` | Одноразовый канал выдаёт фразу назначенному дочернему процессу для текущего ключа. Ошибка запуска, тайм-аут, превышение лимита вывода и отмена уничтожают временные данные. Отмена завершает дерево процессов. |
| `sshExecCancelsOnDisconnectAndChanges` | Отмена MCP, закрытие stdin, правка привязки и блокировка останавливают активный процесс и исключают поздний успешный ответ. |
| `sshExecRecoversOnlyOwnAbandonedStage` | Очистка сохраняет каталог живого процесса и посторонний каталог с похожим именем. Защищённый каталог завершившегося процесса удаляется. |
| `sshExecRealOpenSsh` | Реальный клиент Windows выполняет `hostname` с зашифрованным синтетическим ключом и проверенным ключом хоста. Неверная либо отсутствующая парольная фраза и другой ключ хоста исключают исполнение. |

Последний тест читает настройки из `TOKENBUCKET_TEST_SSH_KEY`, `TOKENBUCKET_TEST_SSH_PORT`, `TOKENBUCKET_TEST_SSH_KNOWN_HOSTS` и `TOKENBUCKET_TEST_SSH_WRONG_HOSTS`. Для обычного прогона без локального SSH-сервера эта проверка помечается как пропущенная.
