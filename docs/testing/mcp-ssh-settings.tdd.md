# Проверки переключателя MCP SSH

Владелец открывает «Настройки → Безопасность», включает SSH и сохраняет настройку. Брокер начинает принимать поиск SSH-привязок и запросы исполнения без перезапуска. Сохранение выключенного состояния отменяет активный запрос и запрещает новые.

## RED и GREEN

- Коммит `69d6d84` добавил проверку отсутствующего переключателя. Локальная команда `ctest --test-dir build -C Release -R '^test_settings$' --output-on-failure` показала 45 пройденных проверок и один ожидаемый отказ.
- В коммите `fc9578e` та же команда прошла после добавления переключателя, сохранения и применения к работающему брокеру.
- Локальный прогон `ctest --test-dir build -C Release -R '^(test_settings|test_preferences|test_agent_win)$' --output-on-failure` прошёл все три цели. QtTest суммарно сообщил 78 пройденных проверок без отказов и пропусков. После добавления быстрых переходов OFF → ON цель `test_agent_win` повторно прошла все 20 проверок за 27,69 секунды. Для проверки Windows OpenSSH использовался локальный SSH-сервер на `127.0.0.1` и синтетический ключ.

| Проверка | Гарантия |
| --- | --- |
| `mcpSshToggleDefaultsOffAndCanBeSaved` | Переключатель выключен по умолчанию. Изменение черновика открывает сохранение. |
| `mcpSshPreferenceIgnoresFallbacksAndInvalidValues` | Сохраняется явный выбор пользователя. Некорректное значение и настройка другого уровня не включают MCP SSH. Явное выключение имеет приоритет над устаревшими флагами. |
| `mcpSshBindFailureKeepsSettingsRetryable` | Занятый канал оставляет MCP SSH выключенным. После освобождения канала можно включить через тот же диалог. |
| `mcpSshFailedOffSaveRevokesAndCanBeRetried` | Ошибка записи оставляет MCP SSH выключенным в текущем сеансе. Сохранение можно повторить после восстановления доступа к настройкам. |
| `sshSettingsEnableAndRevokeWithoutLegacyAccess` | Отмена черновика оставляет брокер выключенным. Сохранение включает поиск SSH и исполнение, а общий поиск и выдача полей остаются недоступны. Команда проходит диалоги согласия и проверки мастер-паролем на синтетическом хранилище. Выключение отменяет запрос и не допускает публикацию результата даже при быстром повторном включении. |
