## Нативный просмотр

Стенд `build/Release/test_e2e.exe --main-window-demo` создаёт только `QTemporaryDir`, вымышленные записи и временный INI; реальный каталог vault не открывается. Флаги: `--dark`, `--compact`, `--capture <png>`. Для захвата используется реальный Qt Windows plugin, затем `QWidget::grab()`.

Через Computer Use проверены: светлое окно 1240 и тёмное 960, Ctrl+K/Ctrl+F, переход Tab к «Новая запись», ввод запроса без результатов и Escape, Избранное (2), Истекают (1), возврат к группе (3) со сбросом срока, несекретная идентичность карточки, показ только вымышленного логина/пароля и меню «Дополнительно» у кнопки. После проверки тестовые процессы завершены. Ошибка привязки координат устранена повторным выбором окна и свежим снимком; другая поверхность не использовалась.

Закрытие в трей, откат сохранения, пустое хранилище, type/tag/sort сочетания и опасные переходы проверены автоматическими тестами; полный повтор каждого сочетания мышью не заявляется.

Все 12 изображений просмотрены. Масштабы заданы `QT_SCALE_FACTOR=1/1.5/2`, системные настройки дисплея не менялись. Имена содержат запрошенную ширину; Windows ограничивала фактический размер доступным экраном:

| Масштаб Qt | Запрос 1240×800: PNG | Запрос 960×700: PNG |
|---|---|---|
| 100% | 1240×800 | 960×700 |
| 150% | 1860×1061 | 1440×1050 |
| 200% | 1924×1062 | 1920×1062 |

На 200% доступная логическая ширина около 960 px, поэтому 1240 логических px при этом масштабе не подтверждены. Тексты состояний, заголовок и основные действия доступны; длинные строки списка сокращаются, карточка и список прокручиваются. Это проверка отрисовки при фиксированном масштабе, а не перемещения окна между физическими мониторами с разным DPI.

## Сборочная среда

Одна повторная конфигурация vcpkg неожиданно начала переустанавливать все пакеты с новыми ABI при прежней версии компилятора. Запуск остановлен; все 32 исходных пакета восстановлены из точных локальных ABI-архивов, списки файлов восстановлены, старый status сохранён, журнал прерванной операции предварительно скопирован. SHA-256 Qt6Core совпал с прежней Release-копией; `vcpkg list` подтверждает установленный комплект.

Далее в локальном CMakeCache использовано `VCPKG_MANIFEST_INSTALL=OFF`: неизменные зависимости повторно не устанавливаются, весь код приложения и тестов собирается штатно. Трековые build-скрипты, версии пакетов и проверки не ослаблялись. Причина изменения ABI не установлена; при изменении зависимостей потребуется обычная конфигурация vcpkg.

Граф исходников обновлён инкрементально: 519 узлов, 1226 связей, 28 сообществ. Изменённые трековые исходники — UTF-8/LF; `git diff --check` без ошибок.
