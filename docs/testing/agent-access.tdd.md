# TDD для локального доступа агента

Сценарии выведены из запроса на доступ агента к данным и SSH-ключам TokenBucket. Первичная реализация прямого помощника появилась до явного запроса на ECC TDD Workflow. Тесты MCP добавлены до его реализации.

| Требование | Проверка | RED | GREEN |
| --- | --- | --- | --- |
| `find` и последующий `read` работают подряд | `test_agent_win::protocolAndOwnerApproval` запускает помощник без паузы после успешного поиска и между разрешёнными чтениями | Первое чтение вернуло код выхода `1` вместо `0` | Ожидается запуск |
| Помощник отклоняет два запроса в одном stdin | `test_agent_win::rejectsExtraStdinRecords` передаёт два корректных JSON-запроса и ожидает `invalid_request` | `locked` вместо `invalid_request` | Ожидается запуск |
| MCP-клиент обнаруживает инструменты и читает разрешённое поле SSH | `test_agent_win::mcpLegacyDiscoveryAndCalls` проверяет рукопожатие 2025-11-25, поиск и повторную проверку перед чтением точных байтов | В ответе `initialize` отсутствует `jsonrpc: "2.0"` | Ожидается запуск |
| MCP-клиент обнаруживает функции сервера и отменяет запрос | `test_agent_win::mcpModernCancellationAndEof` проверяет `server/discover` и метаданные 2026-07-28, отмену активного согласия и закрытие stdin | Для некорректного JSON отсутствует код `-32700` | Ожидается запуск |

`test_agent_win` использует временное хранилище, реальный локальный канал Windows и отдельно запущенный помощник из того же исходника с изолированным именем канала. Проверка охватывает отказ в реальном диалоге, повторную проверку мастер-паролем, SSH с исходными байтами до 1 МиБ, поля других типов, видимость строк, совпадение снимка записи, блокировку, обрыв соединения и одно активное подтверждение. Путь Windows Hello проверяется с подставным системным верификатором и настоящим хранилищем DPAPI, включая поздний успех после обрыва соединения.

Инструменты проекта — CMake, vcpkg и CTest. Команда фокусной проверки Windows: `tools\test.cmd -R "^test_agent_win$"`. Сборка, тесты и измерение покрытия выполняются на локальном компьютере.

В RED сборка `cmake --build --preset default --target test_agent_win --parallel 12` завершилась успешно. CTest вернул код `1`, а QtTest сообщил `4 passed, 4 failed`. Вывод сохранён в локальном `build/evidence/test_agent_win-red.txt`.
