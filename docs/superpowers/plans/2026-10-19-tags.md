# Теги записей — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** теги записей: ввод в редакторе с автодополнением, поиск, фильтр-чипы с условием И, переименование и удаление тега по хранилищу; CBOR v2 с чтением v1.

**Architecture:** поле `QStringList tags` в `model::Entry`; нормализация и лимиты в `VaultModel::setEntry`; версия содержимого `"v"` 1→2 (парсер принимает обе); `allTags/renameTag/removeTag` — операции модели; UI — поле `entryTags` с comma-aware `QCompleter` и панель чипов `tagBar` над списком, фильтр через `refillList`; мутации чипов через существующий `commit()`.

**Tech Stack:** C++20, Qt 6 Widgets, libsodium (транзитивно), Qt Test + CTest; сборка `tools\build.cmd` / `tools\test.cmd`.

**Spec:** `docs/superpowers/specs/2026-10-19-tags-design.md` — план исходит из спеки; исполнитель читает оба документа.

## Global Constraints

- Лимиты тегов: ≤16 на запись; длина тега 1–32 символа; ошибки дословно: «Тегов больше 16.», «Тег длиннее 32 символов.»
- Нормализация: trim, пустые отбрасываются, дедупликация без учёта регистра (сохраняется первое написание).
- CBOR: `"v":2`, запись содержит массив строк `"tags"`; парсер принимает v1 (теги пустые) и v2; отсутствие ключа в v2 — пустой список; не-массив/не-строка/нарушение лимитов в файле — Bad «Хранилище повреждено (теги).»; иные версии — «Неподдерживаемая версия данных.»
- `renameTag`/`removeTag` не меняют `modified` записей; сравнение тегов везде без учёта регистра.
- Фильтр чипов — И по выбранным тегам, работает вместе с поиском, фильтром по типу и сортировкой.
- Файлы UTF-8 без BOM, LF; коммиты от `imtonyromeo`, без AI-атрибуции, без push.
- Запятая — разделитель тегов: тег, содержащий запятую, не выражается (документированное ограничение).

## Review Focus

1. Регистр тега при фильтрации чипами (чип «Прод» против тега «прод») — фильтр обязан находить записи независимо от регистра. Пиннит `test_model: tagsRenameAndRemove` (сравнения CI в rename/remove) и `test_ui: tagBarChipsFilterList` (чип с регистром, отличным от хранения, фильтрует корректно).
2. Граничные лимиты: 16 тегов — успех, 17 — отказ; тег 32 символа — успех, 33 — отказ. Пиннит `test_model: tagsNormalizeAndLimit`.
3. Хранилище v1 открывается и после первой записи становится v2; повторное открытие — теги на месте. Пиннит `test_model: tagsCborV2RoundtripAndV1Reads` (парсер v1/v2; пересохранение — существующими тестами сохранения приложения).
4. Пустое поле тегов — запись без тегов; после удаления последнего тега панель чипов пустеет, выбранные чипы не оставляют «мёртвых» фильтров. Пиннит `test_ui: tagBarChipsFilterList` (сброс чипов) и `test_model: tagsRenameAndRemove` (полное удаление).
5. Запятая и пробелы во вводе: « прод , Web , web » даёт ровно два тега. Пиннит `test_ui: entryTagsPersistThroughEditor`.

```cpp
QStringList VaultModel::normalizeTags(const QStringList& raw) {
    QStringList result;
    for (const QString& rawTag : raw) {
        const QString tag = rawTag.trimmed();
        if (tag.isEmpty()) continue;
        if (std::any_of(result.cbegin(), result.cend(), [&](const QString& existing) {
                return existing.compare(tag, Qt::CaseInsensitive) == 0; }))
            continue;
        result << tag;
    }
    return result;
}
```

```cpp
QStringList VaultModel::allTags() const {
    QStringList tags;
    for (const auto& entry : entries_)
        for (const QString& tag : entry.tags)
            if (std::none_of(tags.cbegin(), tags.cend(), [&](const QString& existing) {
                    return existing.compare(tag, Qt::CaseInsensitive) == 0; }))
                tags << tag;
    std::sort(tags.begin(), tags.end(), [](const QString& a, const QString& b) { return a.compare(b, Qt::CaseInsensitive) < 0; });
    return tags;
}
QString VaultModel::renameTag(const QString& from, const QString& to) {
    const QStringList fromList = normalizeTags({from});
    const QStringList toList = normalizeTags({to});
    if (fromList.isEmpty()) return "Тег не найден.";
    if (toList.isEmpty()) return "Имя тега пустое.";
    const QString oldTag = fromList.first(), newTag = toList.first();
    if (newTag.size() > MaxTagChars) return "Тег длиннее 32 символов.";
    bool found = false;
    for (auto& entry : entries_) {
        auto match = std::find_if(entry.tags.begin(), entry.tags.end(), [&](const QString& tag) {
            return tag.compare(oldTag, Qt::CaseInsensitive) == 0; });
        if (match == entry.tags.end()) continue;
        found = true;
        entry.tags.erase(match);
        if (std::none_of(entry.tags.cbegin(), entry.tags.cend(), [&](const QString& tag) {
                return tag.compare(newTag, Qt::CaseInsensitive) == 0; }))
            entry.tags << newTag;
    }
    return found ? QString() : "Тег не найден.";
}
QString VaultModel::removeTag(const QString& tag) {
    bool found = false;
    for (auto& entry : entries_) {
        auto tail = std::remove_if(entry.tags.begin(), entry.tags.end(), [&](const QString& existing) {
            return existing.compare(tag, Qt::CaseInsensitive) == 0; });
        if (tail != entry.tags.end()) { found = true; entry.tags.erase(tail, entry.tags.end()); }
    }
    return found ? QString() : "Тег не найден.";
}
```

```cpp
namespace {
// Автодополнение последнего незавершённого тега после запятой.
class TagCompleter : public QCompleter {
public:
    using QCompleter::QCompleter;
protected:
    QStringList splitPath(const QString& path) const override {
        const int comma = path.lastIndexOf(QLatin1Char(','));
        return {path.mid(comma + 1).trimmed()};
    }
    QString pathFromIndex(const QModelIndex& index) const override {
        const QString completion = index.data(Qt::DisplayRole).toString();
        const auto* edit = qobject_cast<const QLineEdit*>(widget());
        if (!edit) return completion;
        const QString text = edit->text();
        const int comma = text.lastIndexOf(QLatin1Char(','));
        return (comma >= 0 ? text.left(comma + 1) + QLatin1Char(' ') : QString()) + completion + QLatin1String(", ");
    }
};
}
```

```cpp
    const auto tags = app_.gate() == Application::Gate::Ready ? app_.model()->allTags() : QStringList();
    QStringList alive;
    for (const QString& selected : selectedTags_)
        if (std::any_of(tags.cbegin(), tags.cend(), [&](const QString& tag) { return tag.compare(selected, Qt::CaseInsensitive) == 0; }))
            alive << selected;
    selectedTags_ = alive;
    QLayoutItem* stretch = nullptr;
    while (auto* item = tagBar_->layout()->takeAt(0)) {
        if (item->widget()) item->widget()->deleteLater(); else stretch = item;
    }
    auto* layout = static_cast<QHBoxLayout*>(tagBar_->layout());
    delete layout->takeAt(0);
    for (const QString& tag : tags) {
        int uses = 0;
        for (const auto& entry : app_.model()->entries()) uses += entry.tags.contains(tag, Qt::CaseInsensitive) ? 1 : 0;
        auto* chip = new QToolButton(tagBar_);
        chip->setText(tag); chip->setCheckable(true); chip->setToolButtonStyle(Qt::ToolButtonTextOnly);
        chip->setToolTip(QStringLiteral("Записей: %1").arg(uses));
        chip->setChecked(std::any_of(selectedTags_.cbegin(), selectedTags_.cend(),
            [&](const QString& selected) { return selected.compare(tag, Qt::CaseInsensitive) == 0; }));
        connect(chip, &QToolButton::clicked, this, [this, tag] {
            auto match = std::find_if(selectedTags_.begin(), selectedTags_.end(), [&](const QString& selected) {
                return selected.compare(tag, Qt::CaseInsensitive) == 0; });
            if (match != selectedTags_.end()) selectedTags_.erase(match); else selectedTags_ << tag;
            refillList();
        });
        chip->setContextMenuPolicy(Qt::CustomContextMenu);
        connect(chip, &QToolButton::customContextMenuRequested, this, [this, tag, chip] {
            QMenu menu(chip);
            menu.addAction(QStringLiteral("Переименовать тег…"), this, [this, tag] { renameTag(tag); });
            menu.addAction(QStringLiteral("Удалить тег…"), this, [this, tag] { removeTag(tag); });
            menu.exec(QCursor::pos());
        });
        layout->addWidget(chip);
    }
    if (stretch) layout->addItem(stretch); else layout->addStretch(1);
}
void MainWindow::renameTag(const QString& tag) {
    bool ok = false;
    const auto name = QInputDialog::getText(this, QStringLiteral("Переименование тега"),
        QStringLiteral("Новое имя тега «%1»:"), QLineEdit::Normal, tag, &ok);
    if (!ok) return;
    commit([&](auto& model) { return model.renameTag(tag, name); });
}
void MainWindow::removeTag(const QString& tag) {
    if (QMessageBox::question(this, QStringLiteral("Удаление тега"),
            QStringLiteral("Удалить тег «%1» со всех записей?").arg(tag),
            QMessageBox::Yes | QMessageBox::No, QMessageBox::No) != QMessageBox::Yes) return;
    commit([&](auto& model) { return model.removeTag(tag); });
}
```
